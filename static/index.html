Your taste, not the algorithm's.

PALATE is an agent that plans a real night out. Give it a mood and a few things you love — it resolves them to entities in the Qloo taste graph, queries cultural affinity for every slot, then critiques its own shortlist and fixes weak spots before it recommends anything.

What the agent actually does

GET /search resolves your references to Qloo entity IDs · GET /v2/tags grounds the mood in real tags · GET /v2/insights with signal.interests.entities, signal.interests.tags and signal.location.query ranks each slot · the critique step re-queries with a revised signal set when a slot is weak.

Honest by design

Every recommendation carries its confidence and the exact Qloo request that produced it. When live Qloo calls fail, the app labels the fallback run as simulated instead of pretending.
